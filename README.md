# Text Review Studio v0.6.0

左右比較を中心に、校正・校閲・CMS整形までをブラウザ内だけで扱う静的Webアプリです。  
この版では、操作を左側に常設し、差分をマーカー型で見せながら、原稿ごとの「こだわり」をルールとして残せるようにしました。

## v0.6.0の主な更新

- 左側に常設の作業パネルを追加
  - 探す：文字列、全角／半角、記号、URL、HTMLタグ
  - 整える：空白、記号、表記、改行のプレビュー付き一括処理
  - タグを付ける：選択範囲へのタグ付け、パターン一括処理
  - 見え方を変える：空白・改行・HTML・URL・未確認箇所の表示
- 差分表示を下線中心からマーカー型へ変更
  - 削除：コーラルのマーカー＋取消線
  - 追加：グリーンのマーカー
  - 置換：左右のマーカーと中央ガターの `↔`
  - 通常本文は余計な装飾を避け、紙のように静かに表示
- こだわりセット
  - `浦和公式サイト｜お知らせ記事`
  - `CMS作業｜HTML優先`
  - `自由編集｜提案を控えめ`
- ルールの強さを3段階で表示
  - **絶対守る**：URL・メール・HTMLの保護、重要な固定基準
  - **原則守る**：記号・空白・統一表記
  - **文脈で判断**：見出し、引用、固有表記など
- `今回は残す` と `今後もこの表記を残す` を分離
  - 後者は例外・個別の作法として保存され、同じルールを次回以降は提案しません。
- 厳密モード
  - 「絶対守る」項目が未確認なら、コピー時に明示して確認します。
- 例外一覧
  - 原稿セットごとの例外を確認・解除できます。

## 基本操作

1. 左に比較元、右にCMS作業版を貼り付けます。
2. `左右で比較` を押すと、段落・行を対応させた差分ビューへ切り替わります。
3. 左側の常設パネルから検索、整形、タグ付け、表示レイヤーを操作します。
4. 右端の `確認` レールで、差分・表記・校閲・HTMLの判断が必要な項目を処理します。
5. 右上の `コピー` から、用途に合わせたテキスト、HTML、確認記録をコピーします。

## ローカル処理

- 入力テキストは外部APIへ送信しません。
- 外部CDN、分析タグ、外部フォントは使いません。
- 作業内容・こだわりセット・例外ルールはブラウザの `localStorage` に保存されます。
- 重要原稿は、`… > 作業データを書き出す` からJSONでも控えてください。

共有PCでは、作業後に `… > この画面の内容を消去` を使ってください。

## GitHub Pages公開手順

1. ZIPを解凍します。
2. フォルダ内のファイルをGitHubリポジトリ直下へ置きます。
3. GitHubの **Settings > Pages** を開きます。
4. `Deploy from a branch` を選びます。
5. Branchは `main`、Folderは `/(root)` を選んで保存します。
6. 数分後、表示されたPages URLで開きます。

ビルド不要の静的ファイル構成です。

## ショートカット

- `Ctrl / Cmd + K`：操作パレット
- `← / →`：前後の確認項目へ移動
- `A`：選択中の項目を反映／確認済み
- `S`：選択中の項目を保留
- `Ctrl / Cmd + Z`：元に戻す
- `Ctrl / Cmd + Shift + Z`：やり直す
