# アイコンファイル

このフォルダのファイルはViteからルートURLで配信されます。

- `favicon.ico`
- `favicon-16x16.png`
- `favicon-32x32.png`
- `favicon-48x48.png`
- `apple-touch-icon.png`
- `android-chrome-192x192.png`
- `android-chrome-512x512.png`
- `mstile-150x150.png`
- `site.webmanifest`
- `browserconfig.xml`

アイコンを差し替えるときは、同じ名前の画像を上書きしてください。
