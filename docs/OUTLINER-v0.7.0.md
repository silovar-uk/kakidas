# kakidas v0.7.0 — アウトライン編集

## 画面と導線
- 文の表示名を「アウトライン」に変更。保存済み `sentence` とバックアップ形式はそのまま。
- ワイド画面: アウトライン 42%、段落 38%、URL 20%。921〜1199pxはURLをレールへ畳む。920px以下は既存のタブ。
- Ctrl/Cmd+Shift+1: アウトライン、2: 段落、3: URL。書き口へフォーカスし、入力先を切り替える。Alt+1/2/3は廃止。
- 各アウトライン項目は選択→Enter編集、Tab字下げ、Shift+Tab字上げ、Ctrl+Shift+上下で兄弟移動、左右で枝の開閉・親子移動。編集中Enterは確定して次の行、Shift+Enterは改行。
- 枝へズーム、全体へ戻る、密度切替、詳細パネルに既存のタグ・補足・削除操作を残す。
- 「段落に複製」は元のアウトラインを保持して段落を作る。関連付けリンクはまだ作成しない。

## 保存上の考え方
- 既存の `parent_id` と `sort_order` を使い、階層変更は単一IndexedDBトランザクションで実行。
- 親の存在を検証し、自己参照・子孫への移動・循環参照を拒否。
- 同じ親の兄弟順を0から振り直す。親が変わった場合は元の兄弟順も整える。親の子孫は親IDを保持し自動追随する。
- 直前の構造移動だけ一段階Undoに対応。通常の本文編集のUndoではない。

## 本番移管ゲート
1. 新旧の自動QAが全件合格し、修正による意味の後退がない。
2. 新規作成・保存・階層の移動が再読み込み後も一貫し、データ消失がない。
3. PC/スマホの撮影・閲覧で主要操作が隠れず、可読性を保つ。
4. GitHub ActionsとVercelの同一コミットを確認した後にマージ・本番検証する。
5. 未確認の項目や実機固有制約は合格と表現しない。
